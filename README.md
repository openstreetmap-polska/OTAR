# OTAR 2026

Projekt realizowany w ramach **OpenStreetMap Polska**, mający na celu weryfikację, pozyskiwanie oraz analizę danych o obiektach turystycznych na potrzeby odznaki OTAR 2026. Repozytorium służy do automatyzacji przetwarzania danych GIS oraz monitorowania postępów mapowania.

## Cele projektu
* **Weryfikacja danych:** Identyfikacja i uzupełnianie brakujących obiektów w bazie OpenStreetMap.
* **Automatyzacja:** Cykliczne pobieranie danych za pomocą zapytań Overpass API i ich analiza skryptowa.
* **Wizualizacja:** Generowanie aktualnych zestawień oraz warstw przestrzennych (GeoJSON / GPKG).
